# Portfólio de Projetos e Habilidades

Portfólio de Amarildo Junior, estudante de Engenharia de Computação no CEFET-MG (Campus Divinópolis). Reúne os projetos que desenvolvi e as habilidades que venho praticando, e também serve como projeto final do curso de Git e GitHub.

## Projetos

- **Batalha Naval (Python):** foi um projeto/jogo em modo texto com os modos Jogador x Computador e Dois Jogadores, estatísticas e replay das partidas. Projeto individual da disciplina de Programação em Python.
- **Portfólio Git:** este repositório, usado para praticar minhas habilidades com Git e GitHub

## Habilidades

- Python (programação orientada a objetos, NumPy, Pandas e Matplotlib)
- Java (herança, polimorfismo e coleções genéricas)
- Git e GitHub (branches, Pull Requests, Issues e GitHub Pages)

## Fluxo de trabalho

O repositório foi desenvolvido seguindo o fluxo colaborativo trabalhado no curso:

- **Commits** no padrão Conventional Commits (`feat`, `fix`, `docs`, `chore`)
- **Branches** por tarefa: `feature/secao-projetos`, `feature/secao-habilidades`, `docs/reflexao`, `docs/readme-profissional` e `feat/github-pages`
- **Pull Requests** para integrar as branches na `main`
- **Issues** encerradas automaticamente com `Closes #N` nos Pull Requests
